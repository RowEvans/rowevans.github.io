Game Development

Platformer Game

This was a game I made in four days. I spent time learning update loops, state machines and how to keep track of all of the data on the screen at once. It was very helpful for me to learn these things as I would like to do more game development in the future.

Overview

This project was made in approximately four days, with an average of 2 hours per day on the project. It has very little design, but functionality. This game is currently a backburner game while I work on bigger projects like Autonomous Flight, or GradePath. I hope to return to this project one day as I have always loved playing games and I want to explore more about game design and development.

This runs entirely on pygame, a high-level graphics library to create games and animations. Scrolling through the docs of this library was not enjoyable but helped me to understand how to fundamentally understand a language or library, not just use their stuff.
This is the only library used in this program, runs everything. The main functions of this library used in this program are sprites, which is what allows animation over time with running.
